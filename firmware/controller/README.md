# Controller Firmware

这是控制端固件。

## 作用

- 开启现场 Wi-Fi AP
- 提供轻量网页
- 扫描接收端设备
- 给设备点名
- 给设备改名
- 接收电脑端发布的配置
- 保存当前运行配置

## 设计原则

控制端只做“现场总控”，不承担复杂规则编辑。

复杂规则统一放在 `lan_config` 电脑端页面里做，然后通过 Wi-Fi 发布回来。

## 现场使用

1. 给控制端上电。
2. 电脑或手机连接控制端 Wi-Fi。
3. 打开控制端页面查看当前状态。
4. 必要时做扫描、点名、命名。
5. 复杂配置由电脑端局域网配置页完成。

## 注意

- 控制端页面保持轻量。
- 复杂逻辑不要继续往控制端页面里堆。
- 保存到控制端的只应该是运行用的最终配置。
