# Receiver Firmware

这是接收端固件。

## 功能

- 接收 ESP-NOW 命令
- 响应 START / STOP
- 响应点名识别
- 驱动 LED 灯效
- 作为现场动作执行端

## 当前状态

当前版本先保留为稳定的测试版本，重点是：

- 能烧录
- 能启动
- 能接收控制命令
- 能稳定亮灯

## 编译方式

1. 用 VS Code 打开这个目录。
2. 选择目标芯片 `esp32c6`。
3. 选择串口。
4. 执行 Build / Flash / Monitor。

## 注意事项

- 当前接收端使用的 ESP-NOW 信道应与控制端一致。
- 目前保留了当前稳定的三路灯口测试方案。
- 后续再逐步扩展到完整硬件能力。
