# 常见问题

## 1. 页面提示 `Failed to fetch`

先确认电脑是否真的连到了控制端 Wi-Fi。

如果你是从 `file:///` 打开的页面，建议改用 `D:\MagicProject\lan_config\serve.ps1` 启动的联机页面。

## 2. 为什么页面里不显示 16 个空分组

这是故意改掉的。

空分组只占内部编号，不应该吓到使用者。页面只显示已经启用的分组。

## 3. 保存后文件去了哪里

联机模式下会写到 `D:\MagicProject\lan_config\magic_wand_config.json`。

离线模式下浏览器会下载一个 JSON 文件，你可以把它保存成同样的文件名。

## 4. 刷新以后编辑内容没了

优先点“恢复草稿”。

系统会把未发布的编辑自动存到浏览器本地草稿里。

## 5. 为什么控制端只能做简单操作

因为控制端的闪存和页面空间都有限。

复杂编辑必须放到电脑端，这样项目才可持续。
