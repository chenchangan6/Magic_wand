# 硬件说明

所有模块都基于 ESP32-C6。

## 端口映射

| 名称 | GPIO | 说明 |
| --- | ---: | --- |
| LED1 | IO22 | 代码中的第 1 路灯口 |
| LED2 | IO21 | 代码中的第 2 路灯口 |
| LED3 | IO20 | 代码中的第 3 路灯口 |
| LED4 | IO19 | 代码中的第 4 路灯口 |

## 当前测试状态

当前已知稳定的接收端测试版，先保留 3 路灯口工作：

- LED1
- LED2
- LED3

这是为了保住当前可烧录、可跑的状态。

## 后续目标

最终目标仍然是：

- 4 路 LED 都可独立控制
- 每路默认 25 颗灯珠

## 目前的现实约束

ESP32-C6 的资源有限，尤其是 LED strip 后端和 RMT 通道数量会影响多路灯口的实现方式。

所以目前策略是：

- 先保住稳定运行
- 再逐步补完整硬件能力

## 对使用者的建议

如果你是现场同事，最重要的是记住：

- 不要把硬件灯口和网页上的“组”混淆
- LED1~LED4 是物理灯口
- 分组是软件规则
