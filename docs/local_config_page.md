# 局域网配置页说明

局域网配置页是给电脑用的主编辑器。

## 打开方式

### 联机方式

双击：

- `D:\MagicProject\lan_config\serve.ps1`

它会自动：

- 启动本地页面
- 打开浏览器
- 页面直接访问控制端

### 离线方式

直接打开：

- `file:///D:/MagicProject/lan_config/index.html`

这种方式适合先整理配置，但不建议拿来做实时联机读取。

## 页面按钮说明

### 从控制端读取

把控制端当前配置拉到电脑页面。

### 读取本地配置

优先从电脑同级保存文件中读取；如果没有联机环境，就手动选 JSON 文件。

### 保存现有配置

把当前页面内容保存到电脑。

联机模式下：

- 直接写入 `D:\MagicProject\lan_config\magic_wand_config.json`

离线模式下：

- 浏览器下载 JSON 文件

### 恢复草稿

恢复浏览器自动保存的临时编辑。

### 清除草稿

删除浏览器里的临时编辑。

### 新建分组

创建一个新的有效分组。

页面只显示已启用分组，不会先摆 16 个空卡片。

### 扫描设备

让控制端广播扫描命令，刷新设备列表。

### 一键发布

把当前完整配置发给控制端，并让控制端保存。

### 导出 JSON

查看当前配置的 JSON 预览。

## 设备卡片

每个设备卡片支持：

- 改名
- 勾选所属分组
- 点名测试
- 保存

## 分组卡片

每个分组卡片支持：

- 分组名称
- 备注
- 对接目标分组
- 共享型 / 独立型
- RSSI 阈值
- 保持时间
- 效果说明
- 静默说明
- 模板套用

## 使用顺序

推荐顺序：

1. 读取控制端
2. 扫描设备
3. 设备改名
4. 新建分组
5. 设置分组关系
6. 保存本地
7. 一键发布

## 失败时怎么做

如果控制端读取失败：

- 先离线编辑
- 先保存本地
- 等控制端恢复后再发布

## 这页的底线

它必须做到：

- 人能看懂
- 手机能临时查看
- 电脑能完整编辑
- 结果能保存到本地
- 最后能发布到控制端
